What this mock-up shows

  • One Export page, two ways in. From Grade it arrives with one photo and opens on Preview, as today. From the Library it arrives with the selection as a batch and opens on Grid.
  • Left: export presets. Made and edited only here. A preset holds one or more versions; each version has every setting the Export page has today, plus a file name pattern and a sub-folder.
  • Right: the control panel edits the selected preset. Changes mark it modified until saved. The destination folder belongs to this run, not to the preset.
  • Files are never overwritten. A number is added and the results list says so.
  • Exports use each photo's last saved grade. The grid flags a photo with unsaved changes in Grade, and an SDR-only photo whose HDR version will be skipped.
  • Quick export… (Library right-click, Ctrl+Shift+E) asks only for a preset and a folder.
  • Room is left in the control panel for print settings and a watermark later (not designed here).
