# Technical archive

Dated records for work that is closed: evidence notes, baselines, reviews and
hand-off prompts from past sprints. They are kept because the product
requirement documents in `docs/product/` link to them.

Nothing here describes how the application works today. For that, start at
the [code map](../code-map.md) and the [architecture](../architecture.md).

Do not add new files here while their work is open. When a sprint closes, move
its dated records in and update the links in the same commit.
