            Settings

            General

            Application defaults apply to new source sessions. Saved projects retain their own project settings.

            Updates the active project when one is open and becomes the default for new sources. It does not set export peak, display peak, proof target, or Windows SDR white.

            Auto uses WebGPU when available and falls back safely. CPU compatibility keeps preview rendering on the backend; export quality is unchanged.

            Appearance

            Themes restyle the workspace surround, panels, and text. The image viewer and color-critical instruments (scopes, curves, exposure bands) stay neutral in every theme so they never bias color judgment.

            Default locations

            These folders become the starting location for native dialogs. Clear a folder to use its default. The HDRF preset library contains separate Keyboard Shortcuts and Grading folders and can be revealed in Finder or Explorer.

            Keyboard shortcuts

            Only standard application commands are assigned by default. Select a shortcut, then press a key combination. Backspace clears it; Escape cancels recording.

            Any slider can be assigned Increase, Decrease, and Reset actions. Holding a key repeats; Ctrl makes adjustment 10× finer. On range sliders, Shift snaps to authored semantic landing positions.
