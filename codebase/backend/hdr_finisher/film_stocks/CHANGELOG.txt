What was changed (2026-10-15, format "hdr-finisher-film-stock/1")
----------------------------------------------------------------
The spectral profiles are not shipped. Instead, each <stock>.json holds tables
sampled from spektrafilm's own functions, with spektrafilm's default settings
except: auto exposure off, grain off, halation off, all spatial effects off
(diffusion filters, lens blur, scanner unsharp mask, DIR-coupler diffusion),
'mallett2019' RGB-to-exposure method, linear sRGB in and out, no output
gamut compression, no output transfer function. The tables are:

- input_matrix: linear sRGB to film layer exposure (exact for mallett2019).
- film_curves_plain / film_curves_corrected: the film density curves with the
  per-channel minimum removed, and the same curves before DIR-coupler
  inhibition, on spektrafilm's own 256-point log exposure axis.
- coupler_matrix: spektrafilm's DIR-coupler matrix for negative film.
- print_table: film density to print log exposure, a 33x33x33 grid; includes
  the spectral enlarger with neutral filters and spektrafilm's mid-grey print
  exposure normalisation.
- preflash_raw: print exposure added per unit of spektrafilm preflash.
- print_warmth_log_shift / print_tint_log_shift: change in print log exposure
  at mid-grey for an enlarger Y / M filter shift of -20 CC (a linearised
  stand-in for spektrafilm's filter shift).
- print_curves: the print paper's fitted density curves (256 points).
- scan_table: print density to linear sRGB (D65), a 33x33x33 grid; includes
  the mean of spektrafilm's print glare (0.03 % of the viewing white). Values
  are not clipped.

Numbers are rounded to 7 significant digits. Grain, halation and other
spatial effects are not part of this data. The tables were regenerated by
codebase/tools/bake_film_stocks.py. Checked against spektrafilm's own
simulation with the same settings: mean difference under 0.12 8-bit sRGB
code values, maximum 1 code value, on a ColorChecker, a grey ramp and random
colours, for all six stocks.
