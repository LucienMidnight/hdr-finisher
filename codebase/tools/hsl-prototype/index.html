About this prototype

One correction can contain several included and excluded ranges. Uniformity pulls each included range toward its own center. Exclusions apply across all included ranges; remove an exclusion to restore that hue.

Photos are decoded by the browser into an sRGB preview, limited to 1000 pixels on the long edge. The processing engine accepts floating-point HDR values, but this preview is SDR. RAW/HDR file loading, independent channel corrections and app integration come later.

Range widths and wheel positions use perceptual Oklab hue. Saturation changes chroma; Luminance is an exposure change in stops. Colors outside the monitor gamut are clipped only for this preview.
